سرعت

Det kan der være flere grunde til. For det første er arbejdet hårdt, både fysisk og psykisk. For det andet er lønnen ikke høj nok i forhold til ansvaret. Desuden er der flere ældre i samfundet, så der er brug for flere hænder. Så alt i alt handler det om hårdt arbejde, lav løn og flere ældre.
