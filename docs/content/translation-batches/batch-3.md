## Uncertain items

| Item ID | Reason and draft reading |
|---|---|
| `2020-maj-b.general.q2.answer` | *det kan være billigere at drive* leaves the object of *drive* implicit. The draft reads it as running the hospital and leaves the basis of the cost comparison open. |
| `2020-maj-b.general.followup1.answer` | *en blodprop* names a clot without specifying where it occurs. The draft uses «لختهٔ خون». *køre lidt længere* describes a longer trip, and the draft leaves who drives implicit. |
| `2020-maj-c.sitB.followup1.answer` | *det danske sprog kan blive svækket inden for fagene* leaves the form of weakening open. The draft reads it as a decline in the standing of Danish within the fields of study. *får ikke noget igen* leaves the expected return unspecified, which the Persian preserves. |
| `2020-nov-b.general.q2.answer` | *får mere tid* does not say whose time is involved. The draft reads it as more time being set aside for older people and patients, alongside companionship and care. |
| `2020-nov-c.sitA.followup1.answer` | *skabe afstand* can refer to physical distance or social distance. The draft uses «فاصله ایجاد کند», which allows both readings. |
| `2020-nov-c.sitB.followup1.answer` | *hvis det bliver for meget* leaves open whether *det* refers to training, attention to diet or both. The draft leaves the reference open with «اگر از حد بگذرد». |
